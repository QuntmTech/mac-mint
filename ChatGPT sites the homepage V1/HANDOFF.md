# VPS handoff — MacMint homepage V1

## Start here

Canonical package: `ChatGPT sites the homepage V1/` in https://github.com/QuntmTech/mac-mint. This is now the main homepage at `/`, replacing the former Vite landing page. `/home2` and `/home2/` permanently redirect to `/`, preserving query parameters. The homepage is a static export with working client-side demos; no Node service or homepage API is required at runtime.

## Preserve the existing account portal

The Vite account app remains in `web/`. Its routes are `/login`, `/signup`, `/account`, `/forgot-password`, `/reset-password` and `/verify-email`. Homepage links use the same-origin `/login` and `/signup` paths. Account logos and back-to-home links perform a document navigation to the static homepage.

For the existing cPanel layout (default docroot in `web/scripts/deploy.sh`: `/home/qrkit/macmint.co`):

1. Use Node 22.13+ and install dependencies in both `web/` and this package with `npm ci`.
2. In `web/`, run `npm run build`, then `bash scripts/build-homepage.sh`. This assembles `web/dist/index.html` from this homepage's root export, saves the account entry as `account-app.html`, and retains `/assets/` beside `/_next/`. The old landing component and `/home2` export are removed.
3. Run `npm run test:browser` in `web/`. The preview server mirrors public/account routing, redirects and 404 status; browser tests cover both applications together.
4. Publish with `bash web/scripts/deploy.sh` from the repository root, or add `--publish-built` to publish the exact combined artifact already tested in step 3. The script validates the combined structure, creates a full docroot backup under `.build/site-deploy-backups/`, and replaces only the MacMint-managed routing block. It preserves `/downloads/`, `.well-known`, `cgi-bin` and cPanel-managed files. `DOCROOT=/some/staging/path` selects another existing deployment directory.
5. Test the homepage and all six account URLs directly, including reset/verify URLs with query parameters. Confirm the `/home2` redirect, CSS/JS responses, interactive demos and mobile layout. Account cookie, API/CORS and email-link configuration remain unchanged.

The deployment script now assembles and publishes both applications together. Do not copy the account app's Vite `dist/index.html` directly over the homepage. The Apache and Nginx examples remain routing references; the active cPanel rules are generated by `web/scripts/deploy.sh`.

## Rebuild / change domain

```bash
cd "ChatGPT sites the homepage V1"
npm ci
npm run typecheck
npm test
NEXT_PUBLIC_SITE_URL=https://macmint.co npm run build
```

Deploy the regenerated `site/`. `npm run build` generates HTML, CSS, JS, robots and sitemap; the same domain sets canonical/OG metadata. No `npm start` is used for this static export.
